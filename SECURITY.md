# Security Policy

## Supported versions

This package currently targets Laravel 12 and Laravel 13. Security reports are welcome for installations using these supported framework versions.

| Laravel version | Supported |
| --- | --- |
| 13.x | Yes |
| 12.x | Yes |

## Reporting a vulnerability

Report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/EvanSchleret/laravel-user-presence/security/advisories/new). Do not publish vulnerability details in a public issue. Include the affected package and Laravel versions, the impact, and steps to reproduce when it is safe to do so. Do not include credentials, production data, or other secrets.

The maintainers will review the report and coordinate a response through GitHub.
